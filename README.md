# Pallapu Dileep Kumar - Personal Portfolio Website 🚀

Welcome to the official repository for **Pallapu Dileep Kumar's Personal Portfolio Website**. Built with HTML5, Vanilla CSS3, modern ES6+ JavaScript, glassmorphism UI design patterns, interactive credential modals, and responsive layout architectures.

---

## 🌟 Key Features

- **🎨 Modern Dark Glassmorphic Design**: Custom CSS design system with HSL color palettes, subtle glowing gradients, and smooth micro-animations.
- **📜 41 Verified Technical Credentials & Certifications**: Structured into 7 technical domain categories (MongoDB AI, Cisco Cybersecurity, Software Engineering, Webinars & Summits, and Internship Experience).
- **💼 Official Internship Certificates & LOR Modal Viewer**: Direct action buttons to view high-resolution Internship Certificates, Letters of Recommendation (LORs), and Employment Offer Letters (*TopGrade Innovation, SkillCraft Technology, QSkill / SR INDIA, Infinity Connects Media, Innoknowvex*).
- **🚀 Featured Projects Showcase**: Live project demos and GitHub repository links for Smart Attendance System, Zentro Hub E-Commerce, AI Voice Assistant, and Machine Learning models.
- **📊 Dynamic Stats & Impact Metrics**: Live counters for 41 Certifications, 20+ GitHub Repositories, 7 Internship Experiences, 4 Academic Projects, 25 Technical Skills, and 10+ Technologies Learned.
- **🏢 Official Infosys Springboard Branding**: Custom branding icons integrated across all 12 Infosys Springboard certifications.

---

## 🛠️ Technical Stack

- **Front-End**: HTML5, CSS3, JavaScript (ES6+), FontAwesome 6, Google Fonts (Inter)
- **Design System**: Glassmorphism, CSS Variables, Responsive Grid & Flexbox
- **Libraries**: Canvas API (particle animation), IntersectionObserver API (stat counters)
- **Deployment**: Local dev server on port 3000 / GitHub Pages
